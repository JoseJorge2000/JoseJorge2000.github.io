# josejorge2000.github.io

Public site for **JJ7Gameplays**. Deliberately separate from the game source,
which stays private.

It exists for two things Google requires at a public URL:

- `privacy-policy.html` — required by Google Play before an app can be released
- `app-ads.txt` — must be served from the **domain root**, which a GitHub Pages
  *project* site cannot do. That is the whole reason this repo exists as a user
  site rather than living in the game repo.

`index.html` is a plain landing page, usable as the developer website on the
Play listing.
